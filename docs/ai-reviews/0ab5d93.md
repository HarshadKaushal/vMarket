# 0ab5d93 — feat: restyle shops, products, and transfers with shadcn/ui

## What the commit contains

Tailwind v4, the shadcn `base-nova` components under `frontend/components/ui`, and restyled nav, login, signup, shops, my products, and transfers. `docs/ui.md` records why shadcn was chosen over MUI, Ant Design, Mantine, and plain CSS.

Search and sort are client components over the arrays loaded by the server pages. The badge uses the full list length. Nav links set `prefetch={false}`. `login.module.css` was removed. `/shops/[shopId]` was not restyled.

## Review

The Nest paths are the same: product create, patch, and delete, and transfer publish, accept, and cancel. Zod still runs before `fetch`. React Hook Form was not added.

`DropdownMenuLabel` is not used. On this preset it throws `MenuGroupContext is missing` unless it is inside a group. Fallback `button` styles skip `[data-slot]` so they do not cover the shadcn button. `--primary` is blue so the buttons match the links.

Empty shelves, empty boards, and a search with no matches each have their own sentence. Logged-out offer cards do not render an empty footer of buttons.

## Decision

Restyle the pages that were asked for. Leave the public shelf alone until it is in scope. Keep search in the browser.
