# b66d825 — feat: add the PostgreSQL schema and init migration

## What the commit contains

`schema.prisma`, `prisma7.config.ts`, `docker-compose.yml` with the Postgres 16 service only, and `20261007063300_init/migration.sql`.

The migration creates shopkeepers, shops, products, and transfer requests. It adds the status enum, checks, `open_transfer_board`, the reservation triggers, and `create_transfer_request`, `accept_transfer_request`, and `cancel_transfer_request`. `total_price` is a generated column. `shops.shopkeeper_id` is unique.

## Review

The schema is the TypeScript model. It cannot hold the locks or the "update only if pending" rule, so those stay in the migration. Compose does not start Nest or Next. That matches the decision to add those images later, and it does not yet meet the three-container requirement.

Lock order in the functions is the product row, then the request row.

## Decision

Do not reimplement accept as `prisma.transferRequest.update`. Do not edit this migration after it has been applied. A later schema change is a new migration.
