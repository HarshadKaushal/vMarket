# bf124f9 — chore: keep secrets and build output out of git

## What the commit contains

Root and backend ignore files, the frontend ignore file, and two `.env.example` files. The examples name `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `POSTGRES_PORT`, `DATABASE_URL`, and `JWT_SECRET`. They do not contain a real password or a real JWT secret.

## Review

The ignore rules cover `.env`, `node_modules`, Next build output, and the generated Prisma client. Committing the examples is what makes the setup reproducible. Committing a filled `.env` would publish the database password and the signing secret.

## Decision

Secrets stay on the machine. The examples stay in git with empty or placeholder values.
