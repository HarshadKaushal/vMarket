# 6d2203f — feat: add the Next.js screens for shops, products, and transfers

## What the commit contains

The App Router pages: shops, a shop shelf, signup, login, my products, and transfers. Forms validate with Zod and then `fetch` `/api/...`. `next.config.ts` rewrites `/api` to Nest so the cookie is stored on port 3001. Server components forward the cookie for the profile and for `GET /products`. Public lists do not send it. `cache: "no-store"` is set on those fetches.

## Review

The screens call the Nest routes that already existed. They do not import Prisma. Accept and cancel are separate buttons based on the logged-in shop. Logged-out visitors can see the board.

The styling here is plain CSS. Search, sort, and shadcn came later in `0ab5d93`. The login form did not trim the password yet.

## Decision

Next stays a client of the API. A Server Action must not accept a transfer or open PostgreSQL.
